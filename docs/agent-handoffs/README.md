# Agent handoffs (internal archive)

Dated working records exchanged between operators and agent sessions:
session handoffs, investigation briefs, field findings and implementation
notes. They are preserved for provenance and excluded from the published
documentation site — they are not maintained documentation. Anything still
normative is promoted out of this archive into a published page (for
example, the LAN CIDR allowlist semantics now live in
[lan-cidr-policy.md](../lan-cidr-policy.md)).
